# 个人介绍网站（AI辅助开发）

## 项目说明
这是一个个人简历单页网站，使用 Cursor AI 辅助完成开发，已部署到 GitHub Pages。

 访问地址
线上网站：https://miss551.github.io/my-portfolio/

 技术栈
- HTML5
- CSS3
- JavaScript

 功能与交互
- 个人信息、教育、实习、项目、技能、荣誉展示
- 导航锚点平滑跳转
- 滚动渐入动画
- 卡片悬浮效果

 AI工具使用说明
1. 使用工具：Cursor（AI编程工具）
2. AI完成：
   - 根据简历和作业要求，生成完整网站代码
   - 设计简约风格界面
   - 实现交互动画
3. 本人手动完成：
   - 核对并修改个人信息
   - 本地调试与预览
   - 上传到 GitHub 并配置 GitHub Pages
4. 遇到问题：
   - 不确定交互代码怎么写 → 直接让 AI 生成可用代码
   - 上传冲突 → 先拉取最新再推送
